description: 스킬 이름과 목적을 입력받아 표준 포맷의 .claude/skills/*.md 파일을
작성한다. 새 스킬 아이디어를 정형화하거나 기존 반복 작업을 스킬로 등록할 때 사용한다.
---

## 도메인 특화 규칙

- 프로젝트: RLC Load Bank WPF HMI (.NET 8 / DevExpress / Modbus TCP)
- 스킬 저장 위치: `.claude/skills/{name}/SKILL.md`
- 코드·문서 경로는 하드코딩 금지 — `Resolve-ProjectRoot.ps1` 기준 상대경로 사용
- 500줄 초과 시 스킬을 기능 단위로 분리 작성
- 산출물 파일명 규칙: `{name}-result-{YYYYMMDD}.md`

---

## 절차

1. **스킬 정보 수집**
   - 사용자에게 아래 항목을 확인한다.
     - 스킬 이름 (kebab-case)
     - 목적: 무엇을 하는가 / 언제 사용하는가
     - 관련 파일·도구 (코드, Excel, PowerShell 등)
     - 산출물 형태 (파일 저장 / 터미널 출력 / 확인 요청)

2. **관련 파일 분석**
   - 스킬이 다루는 파일·API를 Read/Grep으로 파악한다.
   - 도메인 특화 규칙(주소 체계, 태그 네이밍 등)을 추출한다.

3. **초안 작성**
   - 아래 템플릿을 채워 스킬 프롬프트 초안을 작성한다.
   - 절차는 번호, 원칙은 글머리로 구분한다.
   - 500줄을 초과하면 서브 스킬로 분리한다.

4. **사용자 확인 (1차)**
   - 초안 전문을 보여주고 수정 요청을 받는다.
   - 수정이 없으면 5단계로 진행한다.

5. **품질 체크리스트 자가 검증**
   - 아래 체크리스트를 직접 확인하고 결과를 출력한다.

6. **사용자 확인 (2차)**
   - 체크리스트 결과를 보여주고 저장 여부를 확인한다.

7. **파일 저장**
   - `.claude/skills/{name}/SKILL.md` 에 저장한다.

---

## 품질 체크리스트

- [ ] `name` + `description`에 "무엇을" + "언제" 모두 포함
- [ ] 절차는 번호, 원칙은 글머리로 구분됨
- [ ] 500줄 이하 (초과 시 분리 여부 명시)
- [ ] 산출물 파일명이 `{name}-result-{YYYYMMDD}.md` 형식으로 명시됨
- [ ] 체크리스트 섹션 포함
- [ ] 템플릿 섹션 포함 (산출물이 문서인 경우)
- [ ] 단계별 사용자 확인이 절차 안에 배치됨
- [ ] 도메인 특화 규칙 섹션 포함
